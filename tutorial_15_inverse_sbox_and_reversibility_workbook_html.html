Inverse lookup rule If \(S(x) = y\), then \(S^{-1}(y) = x\).
The inverse table is the forward table read backward.
Order of operations Forward: field inverse → affine.
Inverse: inverse affine first, then field inverse again.
Round-trip identity \(S^{-1}(S(x)) = x\) for every byte \(x\).
The same intermediate value appears in both directions.
Bijection requirement A reversible S-box maps 256 inputs to 256 distinct outputs.
Any duplicate output makes decryption ambiguous.

Drill 1 — Inverse lookup: given S-box(x) = y, find x

The core rule: if the forward S-box maps \(x \to y\), then the inverse S-box maps \(y \to x\). Practice reading the table in reverse.
