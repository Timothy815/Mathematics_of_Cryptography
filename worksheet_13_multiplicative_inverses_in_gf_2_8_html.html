Quick Reference — tap to expand
Multiplicative inverse: For \(a\in\mathrm{GF}(2^8)\), \(a\ne0\), there exists a unique \(b\) such that \(a\cdot b=\texttt{0x01}\). We write \(b=a^{-1}\).
GF(2⁸) multiply rule: Use the xtime chain — build \(a,\,\text{xt}(a),\,\text{xt}^2(a),\ldots\) then XOR entries selected by the bits of \(b\).
xtime: \(\text{xt}(a)=(a\ll1)\) if top bit = 0; else \((a\ll1)\oplus\texttt{0x1B}\).
Verified pair: \(a\cdot b=\texttt{0x01}\) in \(\mathrm{GF}(2^8)\) \(\Leftrightarrow\) \(b=a^{-1}\).
Identity: \(\texttt{0x01}^{-1}=\texttt{0x01}\). Zero has no inverse.
AES example: \(\texttt{0x53}^{-1}=\texttt{0xCA}\) (used in the AES S-box).

Part D — Special cases

D1. \(\texttt{0x01}^{-1}=\texttt{0x01}\). Verification: \(\texttt{0x01}\cdot\texttt{0x01}=\texttt{0x01}\). ✓

D2. False. \(\texttt{0x00}\) has no inverse; there is no byte \(b\) such that \(\texttt{0x00}\cdot b=\texttt{0x01}\) because zero times anything is zero.

D3. \(\texttt{0x01}\). Any element equal to its own inverse satisfies \(a^2=\texttt{0x01}\); the multiplicative identity \(\texttt{0x01}\) satisfies this trivially.

D4. True. \(\mathrm{GF}(2^8)\) multiplication is commutative, so \(a\cdot b=b\cdot a\).

Part E — Conceptual questions

E1 sample. Because the AES modulus \(m(x)=x^8+x^4+x^3+x+1\) is irreducible over \(\mathrm{GF}(2)\), the quotient ring \(\mathrm{GF}(2)[x]/m(x)\) is a field. In any field, every nonzero element has a multiplicative inverse. Equivalently, any nonzero polynomial \(a(x)\) of degree less than 8 is coprime to \(m(x)\), so the Extended Euclidean Algorithm over \(\mathrm{GF}(2)[x]\) yields coefficients \(u,v\) with \(a(x)u(x)+m(x)v(x)=1\), meaning \(u(x)\) is the inverse of \(a(x)\) modulo \(m(x)\).

E2 sample. In \(\mathrm{GF}(2^8)\) both addition and multiplication are defined over polynomials with binary coefficients, reduced modulo the AES irreducible polynomial. Ordinary decimal multiplication does not reduce modulo anything and does not use XOR for addition, so it gives completely different — and wrong — results.

E3 sample. The two stages are: (1) take the multiplicative inverse of the byte in \(\mathrm{GF}(2^8)\) (mapping \(\texttt{0x00}\mapsto\texttt{0x00}\)); (2) apply an affine transformation over \(\mathrm{GF}(2)\) (a fixed 8×8 binary matrix multiplication plus XOR with the constant \(\texttt{0x63}\)).

E4 sample. Multiplication by zero always produces zero: for any byte \(b\), \(\texttt{0x00}\cdot b=\texttt{0x00}\ne\texttt{0x01}\). Therefore no candidate inverse can satisfy the required equation.
