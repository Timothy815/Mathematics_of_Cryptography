Part E — Linear or Affine

E1. Linear — form y=Av, no constant added.

E2. Affine — form y=Av⊕c; constant c is XOR'd in.

E3. Linear — a permutation matrix is still y=Pv with no constant.

E4. Affine — s=Ab⊕c where c=0x63; adding 0x63 makes it affine.

Part F — Concept Questions

F1 sample answer. No. Two identical rows mean two output bits are always equal, so different inputs can produce the same output — the transformation is not one-to-one and therefore not invertible.

F2. L(u⊕v) = L(u)⊕L(v) = [1,1,0,0]⊕[0,1,1,0] = [1,0,1,0]. Answer: 1010.

F3 sample answer. Linear layers provide diffusion but preserve algebraic structure — a purely linear cipher can be broken by solving linear equations. S-boxes add nonlinearity (confusion), making the system algebraically intractable.

F4. I⁻¹ = I. The identity matrix is its own inverse.
