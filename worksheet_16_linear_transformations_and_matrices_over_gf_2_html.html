Part E — Linear or Affine

E1. Linear — form y=Av, no added constant.

E2. Affine — form y=Av⊕c, constant c added by XOR.

E3. Linear — a permutation matrix is still y=Pv with no constant.

E4. Affine — s=Ab⊕c where c = 0x63; the matrix multiply is linear but adding 0x63 makes it affine.

Part F — Concept Questions

F1 sample answer. No. Two identical rows mean two output bits are computed identically, so different inputs can produce the same output. The transformation is not one-to-one, therefore not invertible.

F2. L(u⊕v) = L(u)⊕L(v) = [1,1,0,0]⊕[0,1,1,0] = [1,0,1,0]. Answer: 1010.

F3 sample answer. Linear layers spread changes (diffusion) but preserve algebraic structure — a purely linear cipher can be broken by solving a system of linear equations. S-boxes add nonlinearity (confusion), making the equations intractable.

F4. I⁻¹ = I. The identity matrix is its own inverse.
