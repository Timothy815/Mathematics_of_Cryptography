Part F — Concept Questions

F1 sample answer. The avalanche effect means that flipping a single input bit causes many output bits to change. This is desirable because it prevents an attacker from making small, controlled changes to plaintext or ciphertext and predicting the effect; changes spread unpredictably.

F2 sample answer. Branch number 3 means that for any nonzero input difference x, the combined count wt(x)+wt(L(x)) is at least 3. At minimum, one active input bit produces at least two active output bits. Differences cannot vanish or stay confined to one bit.

F3. From Part C, every unit-vector input gives a total of 3 (wt=1 + wt(L)=2). The minimum is 3, so the branch number is B = 3.

F4 sample answer. A purely linear cipher can be represented as matrix multiplication. The attacker can collect plaintext-ciphertext pairs and solve a system of linear equations to recover the key. Nonlinear S-boxes make this algebraically infeasible.

F5 sample answer. Hamming weight counts 1s in a single string; Hamming distance counts how many positions differ between two strings. Example: wt(10110) = 3. Example: dist(10110, 10010) = wt(10110 ⊕ 10010) = wt(00100) = 1.
